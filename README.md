# nssk-data

Data Analysis Applications, Tools, and Storage for North Shore Streamkeepers

The NSSK accumulates and disseminates data from many sensor sites over long periods of time.

This project aims to provide a secure, resilient, and available database to consolidate NSSK data sources to inform analyses. 

---
## Datasets
* [CoSMo](./src/cosmo) - DFO datasets for watershed telemetry
* [CoSMo/Solinst](./src/cosmo-solinst) - Intermediate readings of Solinst dataloggers
* [CNV Flowworks](./src/cnv_flowworks) - City of North Vancouver's Flowworks sensor site data collection
* [DNV Flowworks](./src/dnv_flowworks) - District of North Vancouver's Flowworks sensor site data collection
* [CNV Hydrometric](./src/cnv_hydrometric) - City of North Vancouver's watershed flow data.
* [Conductivity-Rainfall Correlation](./src/conductivity-rainfall-correlation) - Time-series correlation of CoSMo conductivity data and CNV Flowworks rainfall data  
* [Chloride Acuity](./src/chloride_acuity) - Focused collection of data around high-conductivity periods in CoSMo data
* [Rainfall Events](./src/rainfall-events) - Determination of sustained rainfall events 
* [Rainfall Event Data](./src/rainfall-event-data) - Focused data collection, correlation, and aggregation during rainfall events 
* [Rainfall Interval Data](./src/rainfall-interval-data) - Focused correlation of several datasets with established 10-minute rainfall intervals 
* [Waterrangers](./src/waterrangers) - Aggregation of citizen-scientist readings from sites
